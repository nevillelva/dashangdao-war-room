# 當沖做多與事件分類驗證（2026-11-15）

資料來源皆為 Supabase 唯讀 SELECT（system_portfolio、premarket_outcome、mops_events、twse_market_snapshot）。信賴區間：命中率用 Wilson 95%，均值用 ±1.96·sd/√n（常態近似）。

## 1. 當沖做多（system_portfolio，trade_type='intraday'、side='long'、status='closed'）

| 月份 | n | 毛報酬均值 | 勝率 | 損益(元，毛) |
|---|---|---|---|---|
| 2026-08 | 2 | −0.495% | 0% | −11,500 |
| 2026-09 | 38 | −0.100% | 44.7% | +11,250 |
| 2026-10 | 54 | −0.874% | 22.2% | −96,167 |
| 2026-11（到 11/13） | 4 | −1.500% | 0% | −6,096 |
| 合計 | 98 | −0.592%（sd 1.868，95% CI −0.96～−0.22%） | | −102,513 |

- 是否含成本：**不含**。`realized_roi` 與 (出場價/進場價−1) 逐月相差 ≤0.005%；`realized_pnl` 也是毛損益（見 `intraday_rules.trade_result`：毛報酬 roi、扣成本 net 另算，寫入資料庫的是毛值）。以 DT_COST 0.435% 估算，淨報酬約 −1.03%（粗估 CI −1.40～−0.66%）。
- 影子單 intraday_shadow 做多 n=5（均值 +1.2%，sd 3.08）：n<30，不下結論，不受本次旗標影響。
- 對照：同期當沖做空 n=61，均值 +0.518%（毛）。
- 限制：僅 3 個月、單一市況；9 月近乎持平，惡化集中在 10 月；n=98 已>30，毛報酬 CI 不含 0，故「資料支持停用」成立。這是樣本內歷史，不保證未來。

處置：`intraday_rules.DT_LONG_ENABLED = False`（預設停用實單做多；做空與影子單照常）。改 True 即回復。

### 結論
- 取得擴產訂單：擴大後命中率回升到 37.8%，樣本期間大盤本身下跌（平均 −0.58%/日），超額報酬≈0（CI 跨 0）。**「看多無效」不成立，也沒有證據支持看多；不改。**
- 股利配息：n=52≥30，超額 −0.72%，CI（−1.70～+0.25%）仍跨 0，勝過大盤中位數 40.4%（CI 跨 50%）。**統計上不顯著，結論不成立；不改。**
- 限制：整體僅約 5 週（10/07～11/11）、單一偏空盤；同日事件彼此相關（未做日層級聚類校正，實際信賴區間會更寬）；T 日收盤到 T+1 收盤的設定與 premarket_outcome（前一日收盤到 brief 日收盤）略有差異；股利配息可能與除息行情混雜，未拆分。
- 後續：樣本累積到更多交易日／不同市況再重算（可用相同 SQL）。

### 設定常數（可回復）
`premarket.NEUTRALIZE_BULLISH_CATEGORIES`，預設 `()`＝維持原看多規則。若日後結論成立，改為 `("取得擴產訂單", "股利配息")` 即把這兩類看多改為中性（類別、重要度不變，並加註旗標）；改回 `()` 即復原。
